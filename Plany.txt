======================================================================
                        GOTOWE PLANY TRENINGOWE
=======================================================================
Poniższy zestaw zawiera gotowe, zbalansowane plany treningowe podzielone 
na główne partie mięśniowe. Każda partia posiada dedykowany zestaw 
ćwiczeń wraz z sugerowaną ilością serii, powtórzeń oraz przerw.

-----------------------------------------------------------------------
1. KLATKA PIERSIOWA (Chest Workout)
-----------------------------------------------------------------------
Cel: Budowa siły i masy mięśniowej klatki, uwzględniając różne kąty.

* Wyciskanie sztangi na ławce poziomej (Główne ćwiczenie siłowe)
  -> 4 serie x 6-8 powtórzeń (Przerwa: 120 sek)
* Wyciskanie hantli na ławce skośnej dodatniej (Górna część klatki)
  -> 3 serie x 10-12 powtórzeń (Przerwa: 90 sek)
* Rozpiętki na bramie z linkami wyciągu górnego (Mocne rozciągnięcie i izolacja)
  -> 3 serie x 12-15 powtórzeń (Przerwa: 60 sek)
* Pompki na poręczach / Dipsy (Dół klatki i triceps)
  -> 3 serie x do załamania (Przerwa: 90 sek)

-----------------------------------------------------------------------
2. PLECY (Back Workout)
-----------------------------------------------------------------------
Cel: Rozbudowa szerokości (najszerszy grzbietu) oraz grubości pleców.

* Martwy ciąg klasyczny (Globalne ćwiczenie siłowe)
  -> 4 serie x 5 powtórzeń (Przerwa: 120-150 sek)
* Podciąganie na drążku nachwytem (Szerokość pleców)
  -> 3 serie x maks powtórzeń / lub z ciężarem x 6-8 (Przerwa: 90 sek)
* Wiosłowanie sztangą w opadzie tułowia / Nachwyt (Grubość pleców)
  -> 4 serie x 8-10 powtórzeń (Przerwa: 90 sek)
* Ściąganie drążka wyciągu górnego do klatki siedząc
  -> 3 serie x 10-12 powtórzeń (Przerwa: 60 sek)
* Przyciąganie uchwytu wyciągu dolnego do brzucha siedząc
  -> 3 serie x 12 powtórzeń (Przerwa: 60 sek)

-----------------------------------------------------------------------
3. NOGI (Legs Workout)
-----------------------------------------------------------------------
Cel: Kompleksowy trening czwórogłowych, dwugłowych oraz łydek.

* Przysiad ze sztangą na plecach (Back Squat)
  -> 4 serie x 6-8 powtórzeń (Przerwa: 120 sek)
* Rumuński martwy ciąg z hantlami / RDL (Tył uda i pośladki)
  -> 4 serie x 10 powtórzeń (Przerwa: 90 sek)
* Wypychanie ciężaru na suwnicy / Leg Press (Czworogłowe)
  -> 3 serie x 12 powtórzeń (Przerwa: 90 sek)
* Uginanie nóg leżąc na maszynie (Izolacja dwugłowych)
  -> 3 serie x 12-15 powtórzeń (Przerwa: 60 sek)
* Wspięcia na palce stojąc (Łydki)
  -> 4 serie x 15-20 powtórzeń (Przerwa: 60 sek)

-----------------------------------------------------------------------
4. BARKI / NARAMIENNE (Shoulder Workout)
-----------------------------------------------------------------------
Cel: Rozbudowa przedniego, bocznego oraz tylnego aktonu barków (efekt 3D).

* OHP - Wyciskanie żołnierskie sztangi stojąc (Przedni akton i siła)
  -> 4 serie x 6-8 powtórzeń (Przerwa: 120 sek)
* Wznosy hantli bokiem stojąc (Szerokość barków / Boczny akton)
  -> 4 serie x 12-15 powtórzeń (Przerwa: 60 sek)
* Wznosy hantli w opadzie tułowia / Face Pulls (Tył barku)
  -> 4 serie x 15 powtórzeń (Przerwa: 60 sek)
* Podciąganie sztangi wzdłuż tułowia do klatki
  -> 3 serie x 10 powtórzeń (Przerwa: 75 sek)

-----------------------------------------------------------------------
5. RAMIONA: BICEPS & TRICEPS (Arms Workout)
-----------------------------------------------------------------------
Cel: Maksymalne napompowanie i rozwój ramion (Trening w superseriach).

* SUPERSERIA A (Masa i gęstość):
  A1. Wyciskanie sztangi wąskim chwytem (Triceps) -> 3 x 8-10 powtórzeń
  A2. Uginanie ramion ze sztangą prostą stojąc (Biceps) -> 3 x 8-10 powtórzeń
  (Przerwa po superserii: 90 sek)

* SUPERSERIA B (Izolacja i kształt):
  B1. Prostowanie ramion na wyciągu stojąc / Sznury (Triceps) -> 3 x 12 powtórzeń
  B2. Uginanie ramion z hantlami z rotacją / Z supinacją (Biceps) -> 3 x 12 powtórzeń
  (Przerwa po superserii: 60 sek)

* SUPERSERIA C (Wykończenie):
  C1. Pompki w podporze tyłem / Dipsy ławkowe (Triceps) -> 3 x 15 powtórzeń
  C2. Uginanie młotkowe z hantlami stojąc (Biceps / Przedramię) -> 3 x 12-15 powtórzeń
  (Przerwa po superserii: 60 sek)

-----------------------------------------------------------------------
6. BRZUCH (Core Workout)
-----------------------------------------------------------------------
Cel: Wzmocnienie gorsetu mięśniowego i stabilizacja.

* Allachy - Skłony tułowia klęcząc przy wyciągu górnym
  -> 3 serie x 15 powtórzeń (Przerwa: 60 sek)
* Unoszenie nóg w zwisie na drążku (Dół brzucha)
  -> 3 serie x 12-15 powtórzeń (Przerwa: 60 sek)
* Plank / Deska klasyczna (Stabilizacja głęboka)
  -> 3 serie x 45-60 sekund wytrzymania (Przerwa: 60 sek)
